Mathematical Derivation ("Schiefer Wurf")

1. Tangential Velocity (v₀)

Rotational speed to linear velocity:

v₀ = ω · r = (2π · RPM / 60) · r

Where ω is angular velocity in rad/s and r is the radius of the blade.

2. Maximum Range Equation

Horizontal distance from elevation h₀:

R = (v₀ / g) · [ v₀ sinθ + √(v₀² sin²θ + 2gh₀) ] · cosθ

For h₀ = 0, this simplifies to R = (v₀² / g) · sin(2θ).

3. Optimal Release Angle (θ_opt)

Differentiating R with respect to θ:

θ_opt = arcsin( 1 / √(2 + 2gh₀ / v₀²) )

When h₀ = 0, θ_opt = arcsin(1/√2) = 45°.
